# 修仙记事本 v2 文案规范（子代理必读）

## 语感（凡人流）
- 资源算计、境界压迫、人情冷暖；短句为主，一句一个画面。
- 写"事"不写"情"：情绪从事件和数字里长出来，不用形容词硬灌。
- 好例子（v1 原文）：
  - 「村里捎来口信，是娘托人写的：『仙山的饭，吃得惯吗？别省钱。』」
  - 「你信任的师兄把你的任务功劳据为己有。你去找执事，执事和稀泥。」
  - 「再回村时，村口老槐树还在，认识你的人却没有了。你站了很久。」
- 反例（禁止）：「贵但值」「这买卖值」「满满的正能量」「破防了」「YYDS」等 AI 腔/网络烂梗。

## 审核红线（碰了就是废稿）
- 禁词：一世、前世、来世、轮回、投胎、享年、重生
- 死亡只写：坐化、兵解、道消（境界不够写"寿元已尽，坐化"）
- 不写：现实品牌、政治、色情、赌博明示（赌石可写，因为是修仙题材惯例）
- 成熟内容（道侣亲密等）事件必须带 minAge（经历年数，显示年龄=经历+12）

## 随机性原则
- 抉择尽量用 outcomes 加权随机，不要"固定哪个好"的明牌选项。
- 每个 choice 事件至少留一个**无 cond 的兜底选项**（防止玩家啥都点不了）。
- 大额扣灵石的选项必须 cond.inv 门控。

## 时间线约束（v5 新增，写事件前必读）
**境界-年龄对照**（显示年龄 = 经历年 + 12；行文默认指经历年；数字取自 pop.js 突破加成 + gm.js 均值）：
- 阶段年龄（典型）：筑基初期 ~60｜筑基后期 ~90｜结丹初期 ~140｜结丹中期 ~200｜结丹后期 ~260｜元婴 ~320｜元婴圆满 ~600｜化神 ~700
- 寿元上限（硬规则，突破逐级累加）：炼气 ~140｜筑基 ~270｜结丹 ~520｜元婴 ~1020｜化神 ~2020（根骨最高再延 ~34）
- NPC 按同一张寿元表：凡人/炼气 ~140 封顶，筑基 ~270，结丹 ~520。

**NPC 生存铁律**（跨境界复用 NPC 前，先算寿元）：
1. 凡人/炼气 NPC 默认只能在炼气、筑基期事件出现（寿元 ~140 封顶）。结丹期起跨境界复用须满足其一：补修仙者身份（默认筑基，寿元 ~270）、或改用"后人"。
2. 【挚友】老友线：寿元是第一优先级。挚友本人（炼气）只允许在炼气、筑基期事件出场；金丹初期必须发坐化讣告（样板 you_6），此后一律写"【挚友】的后人"。后人为修仙者（默认筑基，家族线可逐代晋升：筑基→结丹→元婴），行为与称呼遵守「身份规范」一章（环境先皱眉、NPC 自解破例，禁止平辈自称）。
3. "X年前"必须匹配当前境界年代：结丹期写"百余年前"，元婴期写"数百年前/三百年前"。禁止结丹/元婴事件出现"三十年前入门"类小数字。
4. 具体岁数（岁/载/年）不得越过该境界寿元上限；拿不准就写模糊量词（数十载/数百年）。
5. 孩子出生要对得上爹的死期：爹死了多年才出生的孩子，只能写"遗腹子"且间隔须短；否则改辈分（后人/孙辈/曾孙）。
6. 坊市摊主、情报贩子、执事等跨境界复用 NPC：统一作筑基修士处理，文案里点明"筑基修士"四个字。

## 身份规范（称谓与地位 · v5 新增，写事件前必读）
**称谓体系**（全作统一，一个字都不能混）：
- 炼气＝弟子｜筑基＝师叔（门内）/仙师（凡人、坊市）｜结丹＝真人｜元婴＝老祖｜化神＝神君
- 称谓流变（游戏主题）：金丹中期由「小友」升「道友」，金丹后期升「道兄」，结婴后天下称「老祖」。跨越此链的称谓都是身份事故。
- 「前辈」是通用敬称，可跨境界用；「道友」只用于同阶或商贾寒暄，凡人不能用。

**称号铁律**：
- 「真人」＝结丹专属：筑基被称真人＝废稿（钱庄掌柜事件踩过这个坑）。
- 「老祖」＝元婴专属：结丹期不得自称或被称老祖。
- 凡人称呼修士一律「仙师/上仙/神仙」，不写「道友」；坊市商人若本身是修士（钱庄掌柜等），可统一「道友」。

**跨境界称呼禁忌**（境界压人，称呼先行）：
- 低境界角色不得对玩家称「兄弟/道兄/平辈」，无论当年交情多深。金丹见筑基、筑基见炼气，开口先见礼。
- 亲昵只许由上位者先给：玩家（金丹）可以说「你爷爷，是我兄弟」，炼气挚友不能喊「往后还跟你做兄弟」。
- 旧友重逢的正确写法：想叫「兄弟」却咽回去／手抬到一半停住／话到嘴边先矮半截——情绪从「够不着」里长出来。
- 元婴面前，金丹旧友也要先行礼（样板 yy1_guoren：「结婴前那些称兄道弟的金丹旧友，如今见你都要先行礼」）。

**凡人/低阶行为边界**：
- 凡人/炼气不得与高阶修士并肩作战（禁「背靠背杀散魔修」）；可以拔刀护人，但刀到不了护体真元跟前。
- 低境界 NPC 在斗法、夺宝、战场上只能：旁观、逃命、被保护。
- 凡人商贩对修士：躬身、磕头、称仙师；可以记人情、留心意，不能当街平起平坐。
- 与「时间线约束」第 2 条配合：低境界 NPC 若按剧情需要跨境界出场，行为一律按本节写。

**反差写法（情要留，规矩不能破）**：
- 唯一例外的身份意识必须「硌」一下：环境先皱眉，再由 NPC 自己解释为什么破例。
- 好例子：
  - 「老友捧着丹瓶，半天说不出话。临出门他站住，张了张嘴，那句『兄弟』终究咽了回去，只深深一揖：真人，保重。」
  - 「满坊市的人见你都躬身，只有那家铺子的掌柜，隔着柜台喊你当年的小名。旁人皱眉，他浑不在意：祖辈入门那年起就这么喊的，改不过来了。」（挚友后人线样板，见「时间线约束」第 2 条）
- 反例（禁止）：「往后还跟你做兄弟」「兄弟，是我浑」；凡人挚友与元婴老祖并肩杀敌；筑基被称「真人」、元婴被称「真人」等错阶称号。

## Schema（事件）
```js
{ id: "zb_xxx",            // 筑基期 zb_ 前缀；结丹 jd_；秘境入口 mj_<id>_in；传闻 mjw_<id>
  type: "daily|chance|trib|miracle|flavor",
  cat: "xiulian|ziyuan|zhandou|renji|xinjing|jiyuan",
  realms: [1],             // 0炼气 1筑基 2结丹；通用留白可 [0,1,2]
  cooldown: 4,             // 可复用事件建议 4-8 年
  chain: "链id_序号",       // 需前序已触发
  weight: 1,               // 可选；路线事件引擎自动×2.5
  cond: { min:{}, max:{}, flag:"", flag2:"", notFlag:"", notFlag2:"",
          inv:{"灵石":60}, invMax:{}, gongfa:1, artifact:{"法器":1}, combatMin:120 },
  effect: { attrs:{}, inv:{}, flag:"", gongfa:1, artifact:{"法器":1} },
  choices: [{ text, sub, cond, effect, result, outcomes:[{weight,result,effect}] }],
  highlight: true          // 关键节点才用（记入名场面+日志置顶）
}
```

## 可用 flag / 物品词汇表
- 境界 flags：筑基、结丹、一品金丹、假丹
- 路线 flags：宗门、散修、丹道、剑修、御兽、灵兽、魔修、道侣、道侣坐化、洞天、古经、灵眼、灵植
- 状态 flags：走火入魔、走火未愈、心魔已除、丹毒硬扛、负债、债清、pianzi_shan、chou_jie
- 丹药/物品（inv）：灵石、聚气丹、筑基丹、符咒、凝元丹、结金丹
- 材料（flag）：灵髓/地火莲/天雷竹（炼气）；玄冰魄/炎髓晶/雷灵枝（结丹三宝，**只许秘境产出，事件不许发**）
- 法宝品级：法器/灵器/法宝（effect.artifact 自动取名入包）

## 筑基期经济档位
- 事件收入 30–80 灵石/次；支出 50–150；凝元丹约 40/枚；结金丹 300+（拍卖级）；法宝拍卖 150–400
- 筑基修士的"小钱"是几十，"大钱"是几百，别写成几千
