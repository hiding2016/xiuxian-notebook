# 修仙记事本 v2 文案规范（子代理必读）

## 语感（凡人流）
- 资源算计、境界压迫、人情冷暖；短句为主，一句一个画面。
- 写"事"不写"情"：情绪从事件和数字里长出来，不用形容词硬灌。
- 好例子（v1 原文）：
  - 「村里捎来口信，是娘托人写的：『仙山的饭，吃得惯吗？别省钱。』」
  - 「你信任的师兄把你的任务功劳据为己有。你去找执事，执事和稀泥。」
  - 「再回村时，村口老槐树还在，认识你的人却没有了。你站了很久。」
- 反例（禁止）：「贵但值」「这买卖值」「满满的正能量」「破防了」「YYDS」等 AI 腔/网络烂梗。

## 审核红线（碰了就是废稿）
- 禁词：一世、前世、来世、轮回、投胎、享年、重生
- 死亡只写：坐化、兵解、道消（境界不够写"寿元已尽，坐化"）
- 不写：现实品牌、政治、色情、赌博明示（赌石可写，因为是修仙题材惯例）
- 成熟内容（道侣亲密等）事件必须带 minAge（经历年数，显示年龄=经历+12）

## 随机性原则
- 抉择尽量用 outcomes 加权随机，不要"固定哪个好"的明牌选项。
- 每个 choice 事件至少留一个**无 cond 的兜底选项**（防止玩家啥都点不了）。
- 大额扣灵石的选项必须 cond.inv 门控。

## Schema（事件）
```js
{ id: "zb_xxx",            // 筑基期 zb_ 前缀；结丹 jd_；秘境入口 mj_<id>_in；传闻 mjw_<id>
  type: "daily|chance|trib|miracle|flavor",
  cat: "xiulian|ziyuan|zhandou|renji|xinjing|jiyuan",
  realms: [1],             // 0炼气 1筑基 2结丹；通用留白可 [0,1,2]
  cooldown: 4,             // 可复用事件建议 4-8 年
  chain: "链id_序号",       // 需前序已触发
  weight: 1,               // 可选；路线事件引擎自动×2.5
  cond: { min:{}, max:{}, flag:"", flag2:"", notFlag:"", notFlag2:"",
          inv:{"灵石":60}, invMax:{}, gongfa:1, artifact:{"法器":1}, combatMin:120 },
  effect: { attrs:{}, inv:{}, flag:"", gongfa:1, artifact:{"法器":1} },
  choices: [{ text, sub, cond, effect, result, outcomes:[{weight,result,effect}] }],
  highlight: true          // 关键节点才用（记入名场面+日志置顶）
}
```

## 可用 flag / 物品词汇表
- 境界 flags：筑基、结丹、一品金丹、假丹
- 路线 flags：宗门、散修、丹道、剑修、御兽、灵兽、魔修、道侣、道侣坐化、洞天、古经、灵眼、灵植
- 状态 flags：走火入魔、走火未愈、心魔已除、丹毒硬扛、负债、债清、pianzi_shan、chou_jie
- 丹药/物品（inv）：灵石、聚气丹、筑基丹、符咒、凝元丹、结金丹
- 材料（flag）：灵髓/地火莲/天雷竹（炼气）；玄冰魄/炎髓晶/雷灵枝（结丹三宝，**只许秘境产出，事件不许发**）
- 法宝品级：法器/灵器/法宝（effect.artifact 自动取名入包）

## 筑基期经济档位
- 事件收入 30–80 灵石/次；支出 50–150；凝元丹约 40/枚；结金丹 300+（拍卖级）；法宝拍卖 150–400
- 筑基修士的"小钱"是几十，"大钱"是几百，别写成几千
